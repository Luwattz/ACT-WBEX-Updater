# Changelog

## v1.1.0 — 2026-10-27

- License the project under the MIT License.
- Ask before forcibly closing running Ansys hosts, then revalidate and continue
  the GUI update after they exit; declining cancels without changing the installation.
- Replace the upload drop-zone arrow with a plus icon.
- Include the MIT license in both standalone distributions.

## v1.0.0 — 2026-10-25

- First independent release of ACT WBEX Updater by Intelligent Efficiency Team.
- Install/replace user ACT extensions offline, back up the previous installation,
  verify installed resources and set Load as default without launching Workbench.
- Prefer a valid v241 installation; otherwise select the newest installed version.
- Support WBEX drag and drop, check-only mode, rollback and clear result dialogs.
- Default Dark mode, compact sliding Dark/Light switch and gradual theme changes.
- Synchronize Windows 11 caption colors with the client-area fade.
- Include native DPI-aware, multi-resolution application/taskbar icons.
- Offer a fast-start folder ZIP and an optional self-contained single EXE.
