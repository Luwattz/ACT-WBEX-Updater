修复深色主题下“许可证与第三方声明”窗口周围出现白边的问题。

- 许可证窗口打开时立即应用当前主题背景，内容区周围的留白与窗口保持一致。
- 已打开的许可证窗口继续支持深浅主题切换及主题渐变，保存的许可证内容不受影响。
- 保留完整第三方许可证、离线查看和导出、进程关闭确认、自动备份和失败回退功能。

下载：推荐文件夹 ZIP，完整解压后运行 EXE 并保留 `_internal`；单文件 EXE 可独立运行。
`THIRD_PARTY_LICENSES.zip` 提供第三方许可原文，`BUILD-INFO.json` 记录构建组件，
`VERIFICATION.json` 记录两种布局的验证结果，`SHA256SUMS.txt` 提供附件校验值。

Windows 发布流程会执行完整测试，并在独立目录验证两种布局的启动自检、EXE 版本信息和完整许可证导出。
